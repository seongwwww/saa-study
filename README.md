# SAA Study · 나의 AWS 공부방

답을 숨기고 풀어본 뒤, 틀린 문제를 다시 만나는 개인용 학습 앱입니다.
React · TypeScript · Vite · IndexedDB(Dexie)로 만들었습니다. 로컬 전용 실행과 Supabase 계정별 클라우드 동기화를 지원합니다.

**기본 `main` 브랜치에는 앱 코드와 직접 작성한 사용법 데모 3문제가 들어 있습니다.**
개인 PDF와 추출 데이터는 기본적으로 Git에서 제외됩니다. 공개 사이트의 `gh-pages` 브랜치에는 배포한 문제집과 PDF가 포함되어 있습니다. 비밀번호와 개인 학습 기록은 배포하지 않습니다.
AWS 공식 서비스 또는 공식 문제집이 아닙니다.

## 휴대폰·웹에서 바로 공부하기

GitHub Pages로 무료 배포한 웹사이트입니다. PC 서버를 켜두지 않아도 휴대폰과 PC 브라우저에서 접속할 수 있습니다. 현재 공개판은 725문제, 도표와 원본 PDF를 포함하며 랜덤 학습, 모의고사, 오답노트와 필기를 지원합니다. 문제집은 공개 URL에서 내려받을 수 있습니다.

공개판은 이메일 ID·비밀번호로 회원가입한 뒤 같은 계정으로 로그인하면 PC와 휴대폰의 기록이 자동으로 동기화됩니다. 기존 기록은 **설정 및 백업 → 기존 브라우저 기록 가져오기**로 한 번 가져오세요. 이 버튼은 현재 주소·브라우저에 있던 기록만 가져옵니다. 로컬 서버에 있던 기록은 업데이트된 로컬 앱에서 같은 계정으로 로그인한 뒤 가져오면 됩니다. 휴대폰 브라우저의 ‘홈 화면에 추가’를 사용하면 편하게 다시 열 수 있습니다.

배포본은 로컬에서 `npm run build`로 생성한 `dist`의 내용을 별도 `gh-pages` 브랜치에 게시한 스냅샷입니다. GitHub Pages의 배포 소스는 `gh-pages`의 루트(`/`)이며, `main`에 코드를 푸시하는 것만으로는 공개 사이트가 갱신되지 않습니다. 다시 배포할 때에는 최신 빌드와 필요한 자료를 확인한 뒤 해당 브랜치를 업데이트합니다.

## 빠른 시작

Node.js **22.14 이상**과 Git이 필요합니다. Windows, macOS, Linux에서 다음 명령을 실행하세요.

```sh
git clone https://github.com/seongwwww/saa-study-room.git
cd saa-study-room
npm ci
npm start
```

터미널에 표시되는 **http://127.0.0.1:4173/** 을 브라우저에서 엽니다.
`npm start`는 빌드 후 로컬 서버를 실행하며, `Ctrl+C`로 종료합니다.
첫 실행에는 데모 문제가 나오므로 PDF 없이도 기본 학습 기능을 확인할 수 있습니다. 영역별 모의고사는 출제에 필요한 수의 SAA 문제가 있어야 시작할 수 있습니다.

Fork했다면 자신의 저장소 주소로 clone하세요. Download ZIP으로 받았다면 압축을 풀고 그 폴더에서 `npm ci`부터 실행하면 됩니다.

Windows에서는 한 번 `npm ci`와 `npm run build`를 실행한 뒤 **공부방 열기.cmd**를 더블클릭해도 됩니다. 창을 닫아도 로컬 서버는 유지되며, PC를 재시작하면 다시 더블클릭해서 실행하세요. 코드를 변경하거나 새 PDF를 추가했을 때에는 먼저 다시 빌드하세요.

## 기능

- **공부하기**: 정답·해설 펼치기/접기. 답만 읽은 기록과 직접 푼 점수를 구분합니다.
- **전체 랜덤 학습**: 전체 문제를 중복 없이 섞고 한 문제씩 공부합니다. 순서·현재 위치·답안은 새로고침 후에도 유지됩니다. 번호순으로 돌아가거나 다시 섞을 수 있습니다.
- **모의고사**: SAA-C03 공식 영역 비율에 따라 65·50·20문제를 무작위 출제합니다. 타이머, 자동 제출, 영역별 결과, 오답 복습을 지원합니다.
- **문제 풀기**: 문제 수, 범위, 순서, 미풀이·오답·북마크 대상을 선택합니다. 정답은 제출한 뒤 공개됩니다.
- **오답노트**: 틀리거나 헷갈린 문제를 모아 다시 풉니다. 서로 다른 풀이에서 두 번 연속 맞히면 익숙해짐으로 분류하고, 과거 오답 이력은 유지합니다.
- **북마크와 메모**: 저장한 문제를 다시 찾고 개인 정리를 남깁니다.
- **이어풀기**: 답안, 현재 위치, 미완료 세트를 자동 저장합니다.
- **백업·복원**: 설정에서 기록을 JSON 파일로 옮길 수 있습니다. 복원 전에 확인 창을 표시합니다.
- **읽기 환경**: 글자 크기 조절, 모바일 대응, 코드·도표 이미지 지원.

## 모의고사 출제와 영역 분류

[AWS SAA-C03 시험 가이드](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.html)의 공식 비중을 사용합니다(2026-09-21 확인).

| 영역 | 공식 비중 | 65문제 연습 | 50문제 연습 |
|---|---:|---:|---:|
| 보안 아키텍처 | 30% | 19 | 15 |
| 복원력 있는 아키텍처 | 26% | 17 | 13 |
| 고성능 아키텍처 | 24% | 16 | 12 |
| 비용 최적화 아키텍처 | 20% | 13 | 10 |

소수점 배분은 최대 나머지 방식으로 정수화합니다. 부족한 영역을 다른 영역으로 채우지 않으며, 필요한 문항이 없으면 시작을 막고 부족한 수를 표시합니다. 한 회차 안에서는 중복 출제하지 않지만 회차 간에는 같은 문항이 다시 나올 수 있습니다.

원본에 공식 영역 표시가 없으면 지문과 원문 정답의 단서를 이용해 **규칙 기반으로 추정**합니다. 공식 문항 분류나 전문가의 전수 검수가 아니며, 해설과 오답 보기는 분류에 사용하지 않습니다. 애매한 문항은 검토 권장으로 표시합니다. 공부 화면 또는 모의고사 화면의 ‘문제 영역 검토·수정’에서 대표 영역 하나를 지정할 수 있습니다. 직접 지정한 영역은 다음 출제부터 반영되며 백업에 포함됩니다. 시작한 모의고사는 당시 영역을 저장하므로 나중에 분류를 바꿔도 과거 결과가 바뀌지 않습니다.

직접 만든 `questions.json`의 개별 문항에 `domain`을 지정할 수도 있습니다. 허용 값은 `security`, `resilience`, `performance`, `cost`입니다. 사용자 지정 → 문제집 지정 → 자동 추정 순서로 적용됩니다. 분류는 브라우저에서 실행되며 문항을 외부 서비스로 전송하지 않습니다.

[실제 시험](https://aws.amazon.com/certification/certified-solutions-architect-associate/)은 65문제·130분이고, 채점 50문제와 비채점 15문제로 구성됩니다. 이 앱은 모든 문항을 채점하며 공식 환산 점수나 합격 여부를 추정하지 않습니다. 50문제 연습은 100분, 20문제 연습은 40분입니다. 제한 시간은 화면을 나가도 계속 흐르고, 브라우저를 닫은 동안 만료되면 다시 열 때 자동 채점합니다. 기존 미완료 모의고사도 제한 시간은 연장되지 않습니다.

## 내 PDF 가져오기

PDF 가져오기에만 **Python 3.10 이상**이 추가로 필요합니다. 본인이 사용할 수 있는 자료를 자신의 PC에서 변환하세요.

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/extract.py "C:\path\to\my-questions.pdf"
npm start
```

macOS / Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/extract.py "/path/to/my-questions.pdf"
npm start
```

암호화된 PDF는 터미널에서 비밀번호를 입력합니다. 비밀번호는 출력 데이터에 저장하지 않습니다. 이미 서버가 실행 중이면 종료한 다음 `npm start`로 다시 빌드하세요.

추출기는 **텍스트를 선택할 수 있는 PDF** 중 아래 형식에 맞춘 도구입니다. 모든 PDF의 자동 변환이나 OCR을 지원하지 않습니다.

```text
Q1
문제 지문
A. 첫 번째 보기
B. 두 번째 보기
C. 세 번째 보기
D. 네 번째 보기
Answer: A
설명:
해설 내용

Q2
...
Answer: A, C
```

문제 번호는 별도 줄에 `Q1`, `Q2`처럼 표시되고, 보기는 `A.`부터 `F.`까지 지원합니다. 문제당 `Answer:` 표기는 하나여야 하며, 여러 페이지에 걸친 문제와 삽입 이미지를 연결합니다. 추출 후에는 표·코드·페이지 경계가 있는 문제를 원본과 대조하세요. 원문에 쓰인 정답을 그대로 사용하며 사실 검증이나 정답 교정은 하지 않습니다.

생성되는 파일은 Git에서 제외됩니다:

| 경로 | 내용 |
| --- | --- |
| `public/questions.json` | 개인 문제 데이터 |
| `public/source.pdf` | 원본 PDF 사본 |
| `public/images/` | 문제·보기·해설의 이미지 |
| `extraction-audit.json` | 중복 번호, 누락, 추출 구조 검사 |

추출이 실패하면 기존 문제집을 유지합니다. 서로 다른 PDF와 데모는 별도 학습 공간을 사용합니다. 동일 PDF 파일을 다시 가져오면 같은 문제집으로 인식합니다. PDF 파일을 수정하면 새 문제집으로 취급합니다.

## 직접 문제 데이터 작성하기

`src/demo-bank.json`을 참고해 `public/questions.json`을 만들 수도 있습니다.

- 최상위 `version: 1`, 고유한 `id`, `title`, `questions`가 필요합니다.
- 각 문제의 `id`는 고유해야 하며 `number`는 1부터 순서대로 작성합니다.
- `choices`의 키는 A–F, `answer`는 그 키의 배열입니다.
- `explanation`과 `links`는 문자열 배열입니다.
- 원본 PDF가 없으면 `pageStart`, `pageEnd`를 0으로 설정합니다.
- 이미지는 텍스트 중 `[[image:images/example.png]]`로 넣고 해당 파일을 `public/images/`에 저장합니다.

문제집을 바꿀 때는 새 `id`를 지정해 학습 기록이 섞이지 않게 하세요. 같은 문제집의 문제 ID는 유지해야 합니다.

## 기록과 백업

클라우드 설정이 있으면 학습 기록은 Supabase의 본인 계정과 기기의 IndexedDB에 저장됩니다. 로그인하지 않은 사용자는 DB에 접근할 수 없고, RLS 정책으로 타인의 기록을 읽거나 변경할 수 없습니다. 비밀번호는 Supabase Auth가 처리하며 앱의 학습 테이블에 저장하지 않습니다. 브라우저 캐시도 사용자 ID별로 분리합니다.

변경 후 자동 저장하고, 다시 화면으로 돌아올 때와 30초 간격으로 다른 기기의 변경을 확인합니다. 서버 버전을 확인한 조건부 저장으로 동시 수정에 따른 덮어쓰기를 방지합니다. 서로 다른 문항의 기록은 합치고, 같은 메모의 충돌은 두 내용을 함께 보관합니다. 같은 문제의 답안이나 현재 위치가 충돌하면 해당 동기화에서 로컬 변경을 우선하며, 이미 제출한 시험은 다시 미제출 상태로 바꾸지 않습니다. 연결 실패 시 기기에 보관한 뒤 재시도합니다. 기기 데이터를 지우기 전에는 ‘클라우드 동기화 완료’를 확인하거나 백업을 내려받으세요.

클라우드 설정 없이 clone한 앱은 기존과 같이 로컬 전용으로 실행됩니다. 이 경우 각 주소·브라우저의 기록은 별개이며, 설정의 JSON 백업으로 옮길 수 있습니다. 원본 PDF를 열 때에는 기존 PDF 비밀번호가 필요할 수 있습니다.

## 내 무료 Supabase 연결

1. Supabase Free 프로젝트를 생성하고 SQL Editor에서 [`supabase/schema.sql`](supabase/schema.sql)을 실행합니다.
2. 프로젝트의 URL과 **Publishable key**를 프로젝트 루트 `.env.local`에 설정합니다. DB 비밀번호, Secret key, `service_role` 키는 프런트엔드에 넣지 마세요.
3. Authentication의 Site URL을 자신의 배포 주소로 설정합니다.
4. `npm run build`로 다시 빌드하고 배포합니다. 환경 설정이 없는 일반 clone/CI 빌드는 로컬 전용입니다.

```dotenv
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_PUBLIC_KEY
VITE_AUTH_EMAIL_DELIVERY=false
```

현재 공개판은 간단한 가입을 위해 **Confirm email을 끈 설정**이며, 이메일은 검증되지 않은 로그인 ID로 사용합니다. 이메일 확인·비밀번호 재설정 메일은 제공하지 않습니다. 메일 기능을 사용하려면 별도 SMTP를 연결하고 Confirm email을 켠 뒤 `VITE_AUTH_EMAIL_DELIVERY=true`로 빌드하세요. Supabase의 기본 메일은 프로젝트 팀 외 일반 가입자에게 전송되지 않습니다.

Free 플랜은 현재 DB 500MB를 제공하며 1주간 활동이 없으면 프로젝트가 일시 중지될 수 있습니다. 필요한 경우 Supabase 대시보드에서 재개하세요. 유료 플랜이나 과금 옵션은 이 앱이 자동으로 활성화하지 않습니다.

로그인은 개인 학습 기록을 보호합니다. GitHub Pages에 게시된 문제 JSON·PDF·이미지 및 공개 Git 이력은 정적 공개 자료로 남아 있으며 로그인만으로 비공개가 되지 않습니다.

## 개발 및 기여

```sh
npm ci
npm run dev       # 개발 서버 · 127.0.0.1:4173
npm test          # 공개 데모로 채점, 오답, 백업 검증
```

개발 서버와 실행용 서버는 같은 포트를 쓰므로 동시에 실행하지 마세요.

Fork → 브랜치 생성 → 변경 → `npm test`와 `npm run build` → Pull Request 순서로 기여할 수 있습니다. PR에는 개인 PDF, 추출 데이터, 백업, 비밀번호를 넣지 마세요. `git diff --cached`로 업로드 파일을 확인하세요.
